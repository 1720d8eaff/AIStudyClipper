# Study Clipper 0.12 · 删除设备与沉浸满屏

## 本版新增

- **删除文档与笔记本**。右键左侧条目选择“删除文档…”或“删除笔记本…”。确认窗口列出笔记本名称、所在位置和将一并处理的文档清单，默认焦点停在“取消”，避免误按。
- 删除笔记本时整本移入笔记空间内的 `.study-clipper-trash` 回收文件夹，而不是直接抹除，因此误删可以手动取回；同名重复删除时追加时间戳区分。删除单个文档则是直接移除该文件。
- 删除后，打开的标签、当前编辑内容、最近记录与导图中指向被删内容的关联会一起清理，其余笔记本和文档不受影响。不能删除整个笔记空间根目录。
- **沉浸阅读正文铺满窗口**。此前正文被限制在 820 像素宽的中间一列；现在进入沉浸式后解除宽度限制，左右边距随窗口宽度自适应，退出后恢复居中的可读栏宽。
- **Ctrl+S 现在有明确反馈**。编辑器内按下 Ctrl+S 立即保存当前文档并提示“已保存到本机”。平时输入本就自动保存，此键只是让习惯按键的操作同样有结果。
- **全局摘录默认组合改为 Ctrl+Shift+S**。旧默认 Ctrl+Alt+S 在很多机器上已被其他程序注册，导致注册失败；新默认避开常见占用。注册失败时的提示也改为可操作的建议。
- **后台外部修改检查改用文档修订号**。原先每秒一次的空闲轮询会对每个打开的文档做整段文本比较，文档越长开销越大；现在只比较一个单调递增的整数。8 篇 2 万字文档的空闲轮询耗时从 0.557 毫秒降到 0.042 毫秒。

## 继续保留

多层笔记本、拖动归档、导图关联与复习、八篇正文缓存、即时保存、置顶、PDF 导出、公式与表格渲染、沉浸阅读与自动隐藏控件。

## 验证

- 单元测试全部通过，覆盖删除回收、根目录拒删、嵌套笔记本清理、导图悬空关联清理、快捷键默认值与回退。
- 原生工作流冒烟检查通过；打包后的 EXE 另行验证启动、摘录落盘与配置回环。

## 安装

先在托盘退出旧版，完整解压本包，在 Windows 资源管理器双击“安装并启动.cmd”。安装目录为当前用户 `%LOCALAPPDATA%\Programs\StudyClipper\0.12.0`。无需 Python 或管理员权限。已有旧版配置被识别时沿用原目录；没找到时选择原笔记目录，内容保留。

## 范围

删除笔记本为“移入回收文件夹”而非安全擦除，磁盘空间仍在占用，确认无误后需手动清理。沉浸阅读铺满宽度后，超长行会变宽，阅读舒适度取决于窗口尺寸。全局摘录受 Windows 完整性权限影响，若父进程权限过低需从普通桌面的资源管理器启动。程序尚无可信发布者签名，SmartScreen 信誉提示仍可能出现。

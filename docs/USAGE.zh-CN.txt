Study Clipper 0.12

完整解压，在 Windows 资源管理器双击“安装并启动.cmd”。先从托盘退出旧版。
无需 Python 或管理员权限。保留 _internal、许可目录与 app-manifest.json。
安装到当前用户 %LOCALAPPDATA%\Programs\StudyClipper\0.12.0。
尝试继承已核实旧版的原目录；没找到时选择原笔记目录即可继续。
笔记和设置自动保存。新摘录只追加正文，不添加来源、时间或末尾横线。

• 删除文档／笔记本：右键左侧条目选择“删除…”。笔记本整本移入笔记空间内的回收文件夹，可手动取回；单个文档直接删除。
• 沉浸阅读：点击“沉浸阅读”或 F11。正文现在铺满整个窗口宽度。Esc／F11 返回。
• Ctrl+S：立即保存当前文档并提示结果。平时输入已自动保存，此键只是让习惯按键同样有反馈。
• 导出 PDF：点击文档栏“导出 PDF”，或 Ctrl+Shift+P。导出当前文档与支持的公式。
• 阅读和 PDF 不显示 Markdown 分割线。历史源文保留，代码里的横杠、公式和表格正常。
• Ctrl+N 新建文档，Ctrl+Shift+N 新建笔记本，文件夹加号新建次级笔记本，F2 改名。
• 左侧树拖动归档，或右键“移动到…”。同名不覆盖，子目录、附件与导图关联一起更新。
• 编辑／阅读／分屏／导图对应 Ctrl+1／2／3／4。点击导图节点下关联的文档开始复习。
• 全局摘录默认组合为 Ctrl+Shift+S。在 GPT 等普通权限窗口选中文字，按组合键并松开；也可 Ctrl+C 后点“摘录剪贴板”。
• Ctrl／Alt／Windows／Shift 独立选择。Fn 由硬件控制，无法通用注册。
• 右上图钉可置顶，关闭窗口隐藏到托盘，托盘右键“退出”结束程序。
• 设置底部“管理与卸载版本”检索后自行勾选。只卸载所选已验证程序文件，保留笔记与额外文件。

PDF 使用 A4 与页码，常见公式离线显示，非完整 TeX 编译器。旧文件已有来源文字可手动编辑删除。

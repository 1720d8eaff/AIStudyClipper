# Study Clipper 0.12.0 — Windows

下载 `AIStudyClipper_0.12_Windows.zip`，完整解压后，在资源管理器双击 `安装并启动.cmd`。先通过系统托盘退出旧版。无需单独安装 Python 或管理员权限。

此版本支持全局摘录、Markdown 笔记、多层笔记本、导图关联、沉浸阅读和 PDF 导出。0.12 的变更包括删除文档与笔记本、宽屏沉浸阅读、Ctrl+S 保存反馈，以及默认摘录快捷键 Ctrl+Shift+S。完整行为见仓库 README 与原始更新说明。
